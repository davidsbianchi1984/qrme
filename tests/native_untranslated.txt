# The accountless screen, on the three shells that are not a browser.
# Checked by test_the_strangers_language_on_a_phone.py, and ratcheted.
#
# The browser's half of this is finished: `Public.tsx` reads
# `navigator.languages`, its frame is in ten languages, and the four public
# routes answer in the reader's language.
#
# The three native shells carry the same screen for the same person and it is
# English on all of them. This round supplied the missing input — every shell
# can now resolve a device language without a profile, which nothing could do
# before, because the only language variable in each app came from a profile
# and the reader of this screen has none.
#
# The strings are what is left. Roughly twenty sentences per screen, and the
# console's `pub.*` rows are already translated into ten languages and are
# close but not byte-identical, so this is a porting round rather than a
# translating one.
#
# Deliberately all three or none. Porting one shell would put the objector on
# a localized iPhone and an English Android — which is the per-client mistake
# this audit is named for, made on purpose.
#
