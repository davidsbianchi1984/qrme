# status: backlog — 347 rows
#
# Rows in a shell's L10n table that nothing in that shell asks for. Checked by
# test_a_shell_asks_for_a_key_it_has.py, and ratcheted in two directions: no
# shell may hold more than `ceiling`, and the shells together may not hold more
# than `total`.
#
# **Recorded at 0.47.5**, when the guard was ported here from JIM-mini, where
# it had been running for several releases while this repo carried the same
# three tables and the same risk. It found the defect it exists for on the
# first run: three Android screen *headings* asked for `tab.compose`,
# `tab.posts` and `tab.robots`, which that table did not hold — so those three
# screens were titled with their own key names, in every language.
#
#     asked     does the screen call the localizer
#     mattered  does the localizer have anything to say
#
# The other direction is this file.
#
# ## 0.47.6 — 540 to 350, and the prune that was withdrawn
#
# The 0.47.5 record said 540. This round set out to work that number down by
# reading the rows in clusters, and the first pass produced a prune of 366 —
# rows for screens *another* shell has and this one does not. That prune was
# assembled, run, and then **withdrawn**, because of what the reading turned
# up next.
#
# Every button on the Android shell was a hardcoded English string. Compose has
# no `Button(text)`: a button here is a `Box` with a `Text` inside it, written
# once as a private composable and called by name — `SmallAction("Send")`,
# `BrandButton("Bind")`, `labeledField("Desk id", id, "dsk_…")`. Neither guard
# could see through a wrapper, so those screens read as *asking for nothing*,
# and the rows they should have been asking for read as *asked for by nobody*.
#
# **59 of the 154 rows that prune deleted from the Android table were strings
# still hardcoded on that shell**, and 14 of 133 on Windows. `nmg.t.general`
# through `nmg.t.deals` — the sixteen labels of the Manage tab strip — were
# among them, sitting one line away from a `listOf("General", "Summon", …)`
# that put them on screen in English.
#
#     asked     is this row asked for
#     mattered  is this row asked for *by a call this guard can read*
#
# So the number came down by wiring rather than deleting: 80 label positions on
# the Android shell now go through `L10n`, 33 rows were added for the ones no
# table held, and the four segmented tab strips resolve their keys instead of
# naming their screens in English.
#
# The 350 that remain are the honest residue, and they come off the same
# way — by reading them. The rule this round earned: **a row that looks dead is
# evidence about the guard before it is evidence about the row.**
#
# The two-direction ratchet is JIM's: `ceiling` is a maximum over the three
# shells, so the count could rise on one shell while the check passed, if the
# total were not also held.
#
# ceiling: 148
# total: 347
