# status: backlog — 540 rows
#
# Rows in a shell's L10n table that nothing in that shell asks for. Checked by
# test_a_shell_asks_for_a_key_it_has.py, and ratcheted in two directions: no
# shell may hold more than `ceiling`, and the shells together may not hold more
# than `total`.
#
# **Recorded at 0.47.5**, when the guard was ported here from JIM-mini, where
# it had been running for several releases while this repo carried the same
# three tables and the same risk. It found the defect it exists for on the
# first run: three Android screen *headings* asked for `tab.compose`,
# `tab.posts` and `tab.robots`, which that table did not hold — so those three
# screens were titled with their own key names, in every language.
#
#     asked     does the screen call the localizer
#     mattered  does the localizer have anything to say
#
# The other direction is this file. 540 rows across three shells, translated
# into ten languages, that no screen asks for. That is not one defect; it is
# the residue of thirty rounds of localization in which rows were added ahead
# of the screens that would use them, or left behind when a screen was rewritten
# to say something else.
#
# Recording it rather than deleting it, deliberately. A row here is a claim
# that somebody wrote ten translations for a sentence nobody reads — worth
# working off, and worth working off *by reading each one*, because some are
# rows a screen should be asking for and is not. Deleting 540 rows in one pass
# would bury those.
#
# The two-direction ratchet is JIM's: `ceiling` is a maximum over the three
# shells, so the count could rise on one shell while the check passed, if the
# total were not also held.
#
# ceiling: 208
# total: 540
