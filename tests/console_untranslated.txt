#     mattered  what words does this screen put on the glass

# of a ternary, either side of `&&`, the pieces of a concatenation — and

# ## What this file was for
#
# The sidebar had forty-six labels, every one translated into ten languages,
# and forty-six screens behind those labels on which every string was
# English. `l10n.ts` said so in its own first line — "chrome localization for
# the desktop console" — and three rounds of language audit read that
# sentence as a scope rather than as a finding. Each widened correctly inside
# it: Public.tsx, then Onboarding.tsx, then the native shells. None asked
# what was on the other side of the forty-six translated words.
#
#     asked     is the chrome localized
#     mattered  is anything behind the chrome localized
#
# That was worse than a console uniformly in English, which is why it was
# recorded here rather than folded into public_untranslated.txt. A console
# with no translations tells a Spanish reader the truth on the first screen.
# That one put "Mercado", "Amigos" and "Ajustes" in the sidebar — the app
# answering in their language — and then handed them 1576 English strings the
# moment they clicked. The promise was made by the only part that was kept.
#
# ## What it is for now
#
# The count reached its floor in 0.46.3, over twenty-one releases and about
# 1500 keys. It is no longer a backlog; it is a floor with one row on it, and
# the ratchet holds it there in both directions — a new English string on a
# gated screen fails the suite, and so does a row here that has been fixed
# and not struck.

# Two corrections are worth keeping, because both were the count lying in a
# direction that flattered nobody.

#     asked     is this string rendered to somebody
#     mattered  is this string one a non-English reader cannot read

# The count this file exists to state honestly was overstated by that much.

# **0.45.9.** The one row below is deliberate and stays. `AI ·` is quoted,
# not written: the sentence beside it on TheMark says the line comes back
