# English on QRME's gated console. Checked by
# test_the_nav_is_translated_and_nothing_behind_it_is.py, both directions,
# and ratcheted.
#
# The sidebar has forty-six labels and every one of them is translated into
# ten languages. There are forty-six screens behind those labels, and every
# string on all of them is English.
#
# `l10n.ts` says so in its own first line — "chrome localization for the
# desktop console" — and three rounds of language audit read that sentence as
# a scope rather than as a finding. Each round widened correctly inside it:
# Public.tsx, then Onboarding.tsx, then the native shells. None of them asked
# what was on the other side of the forty-six translated words.
#
#     asked     is the chrome localized
#     mattered  is anything behind the chrome localized
#
# This is worse than a console that is uniformly English, which is why it is
# recorded separately from public_untranslated.txt rather than folded in. A
# console with no translations tells a Spanish reader the truth on the first
# screen. This one puts "Mercado", "Amigos" and "Ajustes" in the sidebar —
# the app answering in their language — and then hands them 1576 English
# strings the moment they click. The promise is made by the only part that
# was kept.
#
# Not translated in this round, and the reason is the same one that has held
# for every ratchet in this repo: 1576 strings is not one round, and a
# half-translated console is harder to use than an English one, because a
# reader can no longer tell which screens they are able to read. The keys and
# the `fill` machinery already exist; what does not exist is the decision
# about order, and that decision belongs to somebody who knows which screens
# matter to which market.
#
# The gated reader is a different argument from the accountless one, too.
# They have a profile, the profile has a language, and the server already
# honours it on every answer it writes — which is precisely what makes the
# English here conspicuous: the model replies in Portuguese inside a frame
# that cannot.
#
