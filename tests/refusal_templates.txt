# English refusals built by interpolation — the sentences this product says
# when it says no, assembled from a template and a value at the moment of
# refusing. Checked by test_the_platform_refuses_in_one_language.py, both
# directions, and ratcheted.
#
# ## Why this file exists
#
# The refusal guard read `ast.Constant` and counted `ast.JoinedStr` without
# looking at it. Every other shape fell through in silence. A round that
# added three refusals — one from a dict of templates, one from an f-string,
# one a plain literal — had exactly one of them noticed.
#
#     asked     is this refusal a string literal
#     mattered  what does this refusal put in front of a person
#
# The extractor now classifies every `HTTPException` detail into one of six
# shapes and fails on a seventh, so a shape nobody has decided about cannot
# pass as a shape nobody can see. Two of those shapes owe a translation and
# had none: the module constants below turned out to be translated already,
# and these 36 templates are not.
#
# ## Why they are recorded rather than translated
#
# A template cannot be a key in `_REFUSALS` as written. `i18n.fill` is the
# mechanism this estate already has for a refusal with a value in it —
# `i18n.fill(i18n.MUST_BE_ONE_OF, field=..., choices=...)` — and twenty-two
# call sites use it correctly. These 36 were written as f-strings
# instead, which means English forever whatever language the reader chose.
#
# The fix for each is a conversion to `i18n.fill` plus a translated constant,
# and doing 36 of them in the round that found them would be a bulk
# rewrite of refusal text with no gate between the finding and the change.
# The number here is the true one; it comes down a file at a time.
#
# `{}` marks where a value is interpolated. The skeleton is what a person
# reads, which is the thing being counted.
#
#
# ## 0.80.0: and the same again, behind `str(exc)`
#
# The count above was 36 when this file was written, from `HTTPException`
# call sites alone. Following the domain exceptions those sites forward
# brings it to 143: the same defect, in the modules rather than the routes.
