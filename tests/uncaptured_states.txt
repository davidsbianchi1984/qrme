# Gallery screens the camera cannot yet photograph, and why each one.

# The gallery has three kinds of screen. A *page* is what a nav tab opens.
# A *state* is something the census numbers separately — `Chat 6,45,83`,
# `Feed 189,190,191` — because a component draws more than one thing a
# person meets. A *page that is not a tab* is reached by a press.
#
#     asked     can the camera reach every tab
#     mattered  can it reach everything the gallery numbers
#
# This round found sixteen nav tabs the shoot list had simply never named
# — not a decision, an omission: the list was typed once and every tab
# added since went into the nav and not into it. Those sixteen, plus four
# card-states and two signed-out pages, are photographs now.
#
# These eighteen are what is left. The number never goes up.

# --- states behind a live session --------------------------------------
199  Waveform · what it is doing
     The strip renders under Chat's `presence`, which exists while a voice
     room is actually carrying somebody's voice. The browser this camera
     drives has no second participant and no microphone behind it, so what
     it would capture is an absent element, and the camera refused.
161  Refusal · not on this plan
     Renders only when a capability gate refuses — `<Refusal error={...}>`
     with an error in hand. Reaching it means driving the console into a
     refusal on purpose, which is a recipe that asks for something the
     seeded account may not have.
