# English refusals — the sentences this product says when it says no.
# Checked by test_the_platform_refuses_in_one_language.py, both directions,
# and ratcheted.
#
# qrme/i18n.py opens with "the persona speaks it everywhere". It does. The
# platform did not: every 4xx an owner received was English, on an account
# where they had chosen Portuguese, where the model answered them in
# Portuguese, and where the console's sidebar was in Portuguese too.
#
#     asked     did the caller state a language
#     mattered  did the profile
#
# One handler now translates every refusal into the reader's own language, and
# the eleven sentences any route can raise — the shared owner and interactor
# checks, the credential checks — are translated. These 142 are not, and pass
# through as English, which is a visible gap rather than a confident error.
#
# ## What this file does not cover
#
# **31 f-string refusals**, down from 49. Sentences built with interpolation
# cannot be keyed on their English source, because at the moment they are
# raised there is no English source — only a result.
#
#     asked     is the refusal a constant we can translate
#     mattered  is every part of it something we can translate
#
# `i18n.Templated` now carries the template and its slots alongside the
# finished English sentence, and eighteen sites were converted. What decides
# whether a site can be is the *slot*, not the frame:
#
#   - a slot holding a token — `en, es, pt`, `openai`, `prf_9f2` — is safe to
#     drop into a translated frame, because it is the same string in every
#     language;
#   - a slot holding prose is not, and a translated frame around an English
#     slot is worse than an English sentence: it reads as a bug, in front of
#     somebody who is already being told no. That is the reason this file
#     refuses to ship a translated plan gate, below, and the reason for the
#     rest of these.
#
# Seven of the thirty-one carry prose this product does not author — a mail
# server's exception, a moderation verdict, a hardware availability string.
# They cannot be translated at all until the slot can be, and no mechanism
# changes that. The other twenty-four are convertible and simply are not
# converted yet.
#
# The mechanism refuses rather than guesses: a slot that fails the whitespace
# test keeps the whole refusal English, so a half-translated sentence is not
# something a future round can produce by accident. See
# `test_a_refusal_whose_english_is_not_a_constant`.
#
# **The plan gate — closed.** This file carried it as an exception for four
# releases: a template whose slots were English prose, where translating the
# frame alone would have produced a sentence half in each language at the one
# moment in this product that stands between somebody and a decision to pay.
#
#     asked     can the frame be translated
#     mattered  can the slots be
#
# They can. Eight capability descriptions and one billing period are a closed
# set this product authors, so they are `i18n.Term`s with translations rather
# than strangers — and `Term` is exempt from the whitespace rule for exactly
# that reason: the rule catches prose *nobody wrote a translation for*, and an
# unmapped `Term` still keeps the whole sentence English.
#
# The plan titles are the one part deliberately left alone. `Basic` and `Pro`
# are what the product is called on the pricing page, in the console's tabs and
# on a receipt, and somebody comparing a refusal against a price list needs the
# same word in both places.
#
# See `test_a_refusal_whose_english_is_not_a_constant`, which asserts the
# sentence arrives whole in each of the nine, and
# `test_gates_answer_in_a_shape_a_screen_can_use`, which drives it through a
# real request because every unit test of it passed while the handler's dict
# branch was dropping the template on the floor.
#
# ## The rule for what is not translated on purpose
#
# One sentence here stays English by decision, not by backlog:
#
#     this deployment is reachable beyond localhost but has no
#     QRME_ADMIN_TOKEN configured — objection review and succession stay
#     closed until it is
#
# The person who can act on it is the operator reading a log, the fix is the
# name of an environment variable, and no reader of a translated version could
# do anything a reader of this one could not.
#
