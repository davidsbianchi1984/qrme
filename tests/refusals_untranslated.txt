# English refusals — the sentences this product says when it says no.
# Checked by test_the_platform_refuses_in_one_language.py, both directions,
# and ratcheted.
#
# qrme/i18n.py opens with "the persona speaks it everywhere". It does. The
# platform did not: every 4xx an owner received was English, on an account
# where they had chosen Portuguese, where the model answered them in
# Portuguese, and where the console's sidebar was in Portuguese too.
#
#     asked     did the caller state a language
#     mattered  did the profile
#
# One handler translates every refusal into the reader's own language, and as
# of this release every constant sentence any route can raise is translated
# into all nine. The count this file carried went 165 → 142 → 82 → 0 across
# four rounds; what is left below the line is the part that is not a count.
#
# ## What this file does not cover
#
# **31 f-string refusals.** Sentences built with interpolation cannot be keyed
# on their English source, because at the moment they are raised there is no
# English source — only a result.
#
#     asked     is the refusal a constant we can translate
#     mattered  is every part of it something we can translate
#
# `i18n.Templated` carries the template and its slots alongside the finished
# English sentence, and eighteen sites were converted. What decides whether a
# site can be is the *slot*, not the frame:
#
#   - a slot holding a token — `en, es, pt`, `openai`, `prf_9f2` — is safe to
#     drop into a translated frame, because it is the same string in every
#     language;
#   - a slot holding prose is not, and a translated frame around an English
#     slot is worse than an English sentence: it reads as a bug, in front of
#     somebody who is already being told no.
#
# Seven of the thirty-one carry prose this product does not author — a mail
# server's exception, a moderation verdict, a hardware availability string.
# They cannot be translated at all until the slot can be, and no mechanism
# changes that. The other twenty-four are convertible and simply are not
# converted yet.
#
# The mechanism refuses rather than guesses: a slot that fails the whitespace
# test keeps the whole refusal English, so a half-translated sentence is not
# something a future round can produce by accident. See
# `test_a_refusal_whose_english_is_not_a_constant`.
#
# **The plan gate — closed.** This file carried it as an exception for four
# releases: a template whose slots were English prose, where translating the
# frame alone would have produced a sentence half in each language at the one
# moment in this product that stands between somebody and a decision to pay.
#
#     asked     can the frame be translated
#     mattered  can the slots be
#
# They can. Eight capability descriptions and one billing period are a closed
# set this product authors, so they are `i18n.Term`s with translations rather
# than strangers — and `Term` is exempt from the whitespace rule for exactly
# that reason: the rule catches prose *nobody wrote a translation for*, and an
# unmapped `Term` still keeps the whole sentence English.
#
# The plan titles are the one part deliberately left alone. `Basic` and `Pro`
# are what the product is called on the pricing page, in the console's tabs and
# on a receipt, and somebody comparing a refusal against a price list needs the
# same word in both places.
#
# See `test_a_refusal_whose_english_is_not_a_constant`, which asserts the
# sentence arrives whole in each of the nine, and
# `test_gates_answer_in_a_shape_a_screen_can_use`, which drives it through a
# real request because every unit test of it passed while the handler's dict
# branch was dropping the template on the floor.
#
# ## The exemption that did not survive being reread
#
# One sentence stayed English by decision for four releases — the 503 from
# `auth.require_reviewer` when a deployment is reachable beyond localhost with
# no `QRME_ADMIN_TOKEN` set. The argument written here was that the person who
# can act on it is the operator reading a log, the fix is the name of an
# environment variable, and no reader of a translated version could do
# anything a reader of this one could not.
#
#     asked     who can act on this sentence
#     mattered  who receives it
#
# The operator is who can act. The receiver is whoever made the request, and
# the branch that raises it is reached precisely when the caller is *not*
# local — an anonymous remote caller who tried objection review or succession
# and is owed a reason in their own language. The variable name is a token: it
# survives every translation verbatim, so an operator reading a translated
# copy still has the fix in front of them. The exemption cost a reader their
# language and bought the operator nothing.
#
# It is translated now, and this section stands in place of the count so the
# reversal is on the record rather than silently absent.
#
# ## Not refusals: sentences raised while the app is wired
#
# The collector derives the exception classes to follow from the handlers
# that stringify them. `ValueError` is correctly among them — plenty of real
# refusals are raised as one — and the sweep then took *every* raise of that
# class in the package, constructors included.
#
#     asked     is this sentence raised through a class a route stringifies
#     mattered  can a person reach the place it is raised
#
# These 2 were never owed a translation. Each fires in an `__init__`,
# from environment variables, while the app is being built: there is no
# object yet, no request to answer and no reader — if one ever fired the
# process would not start. They left this backlog without being translated
# because they were never in it by right.
#
#   CloudModelClient needs base_url or a client
#   PDIClient needs base_url or an injected client
#
# `_constructor_sentences` applies the exemption and
# `test_a_wiring_precondition_is_not_a_refusal` checks it in both
# directions — forward, that each really is raised inside a constructor;
# backward, that none is *also* raised where a request can reach it. An
# exemption nothing verifies is a place to hide sentences that are owed.
