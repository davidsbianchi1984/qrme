# ## The register, which is not on this list
#
# The largest systematic cause is not vocabulary. It is who the product thinks
# it is talking to:
#
#     German      Sie / Ihnen / Ihre      du / dein / dich
#     console            204                     32
#     phone                7                     60
#
# The desktop addresses a German reader formally and the phone informally. In a
# language with a T–V distinction that is a claim about the relationship, and
# this product made both at once — *Wo Sie stehen* on the desktop against *Wo
# du stehst* on the phone, *Ihre Signatur-Berechtigungen* against *Deine
# Signaturberechtigungen*. Spanish is milder and mostly settled (20 rows say
# *usted* against 47 that say *tú* in the console, 2 against 13 on the phone);
# French and Portuguese are formal on both sides, Italian informal on both.
#
# Every row this round reconciled moved onto the phones' wording, and so onto
# *du* and *tú*. **The whole-table sweep is not done and is not on this list**,
# because German T–V is not a pronoun substitution — *Wo Sie stehen* becomes
# *Wo du stehst* — and the rule against machine-mangling text a person relies
# on applies to 204 rows as much as to fourteen. It is named here so that the
# next round does not have to find it again.
#
