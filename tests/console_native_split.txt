# ## The register, which is not on this list
#
# The largest systematic cause is not vocabulary. It is who the product thinks
# it is talking to:
#
#     German      Sie / Ihnen / Ihre      du / dein / dich
#     console            204                     32
#     phone                7                     60
#
# The desktop addresses a German reader formally and the phone informally. In a
# language with a T–V distinction that is a claim about the relationship, and
# this product made both at once — *Wo Sie stehen* on the desktop against *Wo
# du stehst* on the phone, *Ihre Signatur-Berechtigungen* against *Deine
# Signaturberechtigungen*. Spanish is milder and mostly settled (20 rows say
# *usted* against 47 that say *tú* in the console, 2 against 13 on the phone);
# French and Portuguese are formal on both sides, Italian informal on both.
#
# Every row this round reconciled moved onto the phones' wording, and so onto
# *du* and *tú*. **The whole-table sweep is not done and is not on this list**,
# because German T–V is not a pronoun substitution — *Wo Sie stehen* becomes
# *Wo du stehst* — and the rule against machine-mangling text a person relies
# on applies to 204 rows as much as to fourteen. It is named here so that the
# next round does not have to find it again.
#
# ## What 0.48.0 did to this number
#
# Widened it. Reconciling the Desk and the Counter picked *Theke* for the Desk
# so German would stop naming two tab-bar entries *Schalter*. The console still
# said *Schalter*, and nothing compared the two tables, so a fix in one opened
# a gap with the other. The round could not have known; this file is the answer
# to that.
#
# ## What is left, and why
#
# Every row below is a question about the English rather than a translation
# mistake — the same distinction `native_split_wordings.txt` leads with.
#
#   * the pronoun family. *Show it*, *Take it back / down / off*, *Wear it*,
#     *Say something in it* — Spanish must agree with what *it* is, and the
#     console's *it* and the phone's *it* are different objects.
#   * *Trade*. The console's row is the trade a person practises (*Gewerbe*,
#     手艺); the phones' is commerce (*Handel*, 交易). One English word, two
#     jobs, recorded in `native_split_wordings.txt` for the same reason.
#   * *Withdraw*. Reflexive on the console's exchange screen, transitive on the
#     phone's people screen.
#   * **Corrected in 0.48.2.** Two rows were recorded here as cases where the
#     three shells disagree with each other, leaving no native wording to
#     adopt. Only one of them was: `action.sign_out` really did read *Sair* on
#     the phones and *Terminar sessão* on the desktop shell, and is now

#     Android-only and agree with each other, so a native wording had been
#     available the whole time; the row was a plain console disagreement
#     misfiled as a harder one, and it is reconciled rather than recorded.

#     The third axis itself is now measured and closed —
