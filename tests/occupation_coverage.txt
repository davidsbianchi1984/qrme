# status: ratchet — the share of the pool a group reaches.
#
# One line: COVERED  <n>  of  <total>. The guard reads it and fails when
# the pool's real coverage drops below the recorded share, so this number
# may rise and may not fall.
#
# ## Why a ratchet and not a target
#
# The pool holds 45,153 positions and 529 of them were written by hand.
# The other 44,624 arrived as titles from published taxonomies and take
# their skills from one of sixteen families, which is sixteen answers to
# forty-five thousand questions. It reads as repetition on a good day and
# is wrong on a bad one: `Commercial Housekeeper` claimed it reconciled a
# till, `Animal Caregiver` claimed it drafted referrals to crisis
# services, and every one of 17,878 skilled-trades titles claimed the
# same five things.
#
# Groups fix that a shape of work at a time, and there is no sitting in
# which they all get written. A number that may only rise turns a job too
# big to finish into a job that cannot quietly go backwards — the same
# reason the divergence records and the doorless lists only shrink.
#
# ## What raising it means
#
# Add rules to `tools/occupation_groups.py`, rebuild the pool with
# `python3 tools/build_occupations.py`, run this test, and write the new
# number here. Lowering it is a deliberate act with a reason beside it,
# not something a rebuild does by accident.
